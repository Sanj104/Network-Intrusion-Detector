This system uses machine learning models trained on the NSL-KDD dataset to classify network traffic as Normal or Attack. The application helps identify malicious activity and demonstrates how AI can assist cybersecurity analysts.

The NSL-KDD dataset resolves inherent problems in the original KDD'99 dataset — removing redundant records to ensure classifiers are not biased. With 41 network traffic features, our model achieves a 0.964 ROC AUC score.
